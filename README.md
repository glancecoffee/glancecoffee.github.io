# قلانس — GLANCÉ · قهوة مختصة

المنيو الرقمي لقلانس + سيستم استقبال الطلبات من الطاولة.

- **المنيو:** `index.html`
- **لوحة صاحب المكان:** `owner.html`

## اللي فيه

- منيو كامل — ٤ أقسام / ٢٦ صنف بصورة لكل صنف، الأسماء عربي/إنجليزي زي
  المنيو المطبوع، وضع فاتح وداكن.
- «الأكثر طلبًا» وكومبوهات وعروض بعدّاد وقت.
- طلب من الطاولة: أحجام/اختيارات، إضافات، ملاحظة للباريستا، واقتراح
  «الناس تاخذه مع».
- الطلب بيتبعت على واتساب مكتوب — من غير أي تطبيق ولا حساب.
- كارت ولاء، وفلتر تقييمات بيوصل الملاحظات لصاحب المكان قبل ما تنزل قوقل.
- لوحة تحكّم: المبيعات، الأصناف، الطلبات، العملاء، التقييمات، وتحكّم فوري في
  المنيو (تقفل صنف أو تغيّر سعر والمنيو يتغيّر في نفس اللحظة).

## التشغيل محليًا

```bash
python -m http.server 8825 --directory .
```

## الملفات

| الملف | بيعمل إيه |
|---|---|
| `index.html` + `assets/menu.*` | المنيو وواجهة الطلب |
| `owner.html` + `assets/owner.*` | لوحة التحكّم |
| `assets/sys.js` | التتبّع والتخزين والتجميع |
| `data/menu.js` | الأقسام والأصناف والأسعار |
| `data/sales.js` | العروض والإضافات والكومبو والولاء |
| `assets/img/items/` | صورة لكل صنف |
| `assets/img/raw/` | شيتات ٣×٣ الأصلية قبل التقصيص |

**تغيير صورة صنف:** استبدل الملف في `assets/img/items/` بنفس الاسم — مفيش تعديل كود.
**تغيير سعر أو صنف:** من `data/menu.js`، أو من اللوحة مباشرة بدون ما تلمس الكود.

## الهوية

- **الألوان:** كريمي ورقي `#FBF4EA` × تان `#A87E5C` × حبر `#3B2E24`
  (مأخوذة من اللوجو والمنيو المطبوع).
- **الخطوط:** `Reem Kufi` للوردمارك والعناوين العربية، `Jost` للاتيني
  (أقرب حاجة لخط GLANCÉ)، `Almarai` للنص.
- **اللوجو:** مرسوم SVG داخل `index.html` (`<symbol id="gmark">`) — الكبسولة
  والبريق والأشعة و«20 21» و«GLANCE» على قوس. بيترسم لوحده أول ما الصفحة تفتح.
